# Tester-Lessons (ki-investment)

- 2026-07-12 (S-006) — **`docker-compose.yml` (db-postgres-Template) published den `db`-Service standardmässig NICHT auf einen Host-Port** — nur der interne Compose-Netz-Zugriff (Service-Name `db`) ist vorgesehen (Migrations-Container liest `DB_HOST=db`). Für einen lokalen Tester-Lauf von `alembic upgrade head` direkt via `uv run` (statt über den Migrations-Container) braucht es einen temporären Port-Publish, sonst `Connection refused` auf `localhost:5432`. Vorgehen: lokale `.env.db` (NIE committen) mit Test-Credentials anlegen, danach `docker compose -f docker-compose.yml -f <override-mit-ports-5432:5432>.yml up -d db` starten, auf `healthy` pollen (`docker inspect --format='{{.State.Health.Status}}' <container>`), Migration mit `POSTGRES_DB/POSTGRES_USER/POSTGRES_PASSWORD` + `DB_HOST=localhost DB_PORT=5432` env-Vars laufen lassen. Nach dem Lauf `docker compose down -v` + Override-Datei und `.env.db` wieder löschen (nicht Teil des Diffs).
